- **定时从缺陷列表取任务，在 git worktree 里分头改** — 有人用自建 n8n + Codex：按计划从 GitHub Issues 或 Notion 取任务，每个任务单独 worktree，由主编排协调实现／重构／测试／文档子 Agent，人主要负责规格、测试和审查，合入前还有多模型代码评议；不自动合并或关闭 issue · [链接](https://agentusecases.ai/use-case/work-through-bug-lists-on-a-schedule-in-git-worktrees) · 跟进：是
